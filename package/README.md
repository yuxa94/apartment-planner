# PLANBY 단위세대 평면 계획 — 단일 파일 패키지

Stage 1(단위세대 계획) 편집기를 HTML 파일 하나로 묶은 패키지입니다. 서버·설치·API 키 없이 열리며, Claude나 ChatGPT 대화와 복사·붙여넣기로 주고받으며 평면을 고칩니다.

| 파일 | 용도 |
|---|---|
| `planby-unit-planner.html` | 편집기 본체 (CSS·스크립트 내장, 약 200 KB) |
| `MODEL-INSTRUCTIONS.md` | Claude 프로젝트 / ChatGPT 맞춤 GPT에 넣을 지침 |
| `planby-unit-planner.artifact.html` | Claude 아티팩트 게시용 (문서 틀 없음, 다운로드 대신 복사) |
| `planby-unit-planner.zip` | HTML·README·지침 묶음 (업로드·전달용) |

## 띄우는 방법

**브라우저 (가장 확실함)** — `planby-unit-planner.html`을 더블클릭합니다. 작업은 그 브라우저에 자동 저장되고, 대화는 옆 탭의 Claude 또는 ChatGPT에서 합니다.

**Claude (claude.ai)** — 게시된 아티팩트: https://claude.ai/artifact/JYNvZGPWkgR3W4XdVsYtLh (비공개, 공유는 페이지의 Share 메뉴에서). 아티팩트용 파일은 `planby-unit-planner.artifact.html`이며, 다운로드 대신 내용 복사 창을 띄우고 확인창 대신 버튼을 한 번 더 누르게 합니다. 다시 게시하려면 Claude Code 세션에서 "패키지를 아티팩트로 다시 게시해줘"라고 요청합니다. 대화창에 HTML을 붙여넣고 아티팩트로 띄워 달라고 할 수도 있지만, 파일이 커서 Claude가 코드를 그대로 다시 써야 하므로 느리고 잘릴 수 있습니다.

**ChatGPT** — 캔버스 미리보기는 코드 전체를 캔버스에 넣어야 해서 이 크기의 파일에는 맞지 않습니다. HTML은 브라우저에서 열고, 대화는 ChatGPT에서 하세요. 맞춤 GPT를 만들면 `MODEL-INSTRUCTIONS.md`를 지침에 넣습니다.

> 대화 앱 안의 격리된 화면(아티팩트·캔버스)에서는 브라우저 저장과 클립보드가 막힐 수 있습니다. 이때도 편집기는 동작하며, 요청문은 대화 말풍선의 입력칸에서 직접 선택해 복사할 수 있습니다. 작업을 지키려면 **프로젝트 저장**으로 JSON 파일을 받아 두세요.

## 대화로 고치는 순서

1. 오른쪽 **✧ Claude 대화**에 요청을 쓰고 **요청 복사** (필요하면 **✎ 영역 표시**로 빨간 영역 A, B…를 그린 뒤 “영역 A로 현관을 옮기고 내부를 다시 배치해줘”처럼 씁니다).
2. 복사된 요청문을 Claude 또는 ChatGPT 대화에 붙여넣습니다. 요청문에는 현재 도면 JSON, 규칙, 영역 좌표가 모두 들어 있습니다.
3. 답변 전체를 같은 입력칸에 붙여넣으면 **답변 검토**로 바뀝니다. 말풍선에서 결과(공간 수, 빈 영역, 외곽 이탈)를 확인하고 **이 수정안 적용**을 누릅니다. Ctrl+Z로 되돌릴 수 있습니다.

요청을 보낸 뒤 화면에서 도면을 고치면 개정 번호가 달라져 답변이 거부됩니다. 이때는 요청문을 다시 복사해 보내세요.

## 이 패키지에 없는 것

- 참고도면 이미지(59A·74A·84A)와 겹쳐 보기 — 용량 때문에 뺐습니다. 원본은 [LH 양주회천 A-26 평면 안내](https://www.lh-hca26.co.kr/sub03_01.html?tab=1).
- 동평면 조합·단지배치 단계 — 각 단계 브랜치에서 개발 중입니다.
- 법정 전용면적 산정과 법규 판정 — 화면의 면적은 계획용 개략값입니다.
