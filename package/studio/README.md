# PLANBY 공동주택 초기계획 스튜디오 — 1·2·3단계 통합 패키지

단위세대 계획 → 동평면 조합 → 단지 배치 검토를 HTML 파일 하나에 묶었습니다. 서버·설치·API 키 없이 열립니다.

| 파일 | 용도 |
|---|---|
| `planby-studio.html` | 세 단계 전체 앱. 더블클릭해서 브라우저로 엽니다. |
| `planby-studio.artifact.html` | 같은 앱의 Claude 아티팩트용 파일(문서 뼈대 없음). |
| `planby-project.json` | 앱에 들어 있는 시작 프로젝트. 다른 브라우저에서 **불러오기**로 엽니다. |
| `unit-59.json` · `unit-74.json` · `unit-84.json` | 동평면 조합이 쓰는 세대 평면(`apartment-planner-unit/1`). |

## 들어 있는 작업본

2026-10-19에 각 단계 브라우저에 열려 있던 작업을 합쳤습니다.

- **단위세대(Stage 1, 개정 183)**: 59형·74형·84형 참고도면 조닝과 빈 도면 “59 v1”.
- **동평면 조합(Stage 2)**: 저장한 안 2개(3세대 59×1 + 74×2, 4세대 59×3 + 74×1). 후보 탐색은 위 Stage 1 도면을 씁니다.
- **단지배치(Stage 3, 개정 474)**: 101~105동(동평면 형상 포함), 청주시 조례 프리셋 기준 검토 조건, 배치안 버전 4개(작업 중 · 원래 · A안 정남향 · B안 남동향).

통합 프로젝트의 개정 번호는 1부터 다시 시작합니다. 이전 단계 브라우저에서 만든 요청문의 patch는 개정 번호가 달라 적용되지 않으니 이 앱에서 요청문을 다시 만드세요.

## 알아 둘 점

- 작업은 앱을 연 브라우저에 자동 저장되고, 다음에 열 때는 저장된 작업이 내장 프로젝트보다 우선합니다. 다른 곳으로 옮길 때는 **프로젝트 저장** → **불러오기**를 씁니다.
- 동평면 조합에서 저장한 안을 대지에 놓으려면 후보의 **JSON ↓**로 받은 파일을 단지 배치 검토의 **불러오기**로 엽니다.
- 참고도면 이미지(59A·74A·84A)와 겹쳐 보기는 용량 때문에 뺐습니다.
- 모델 지침: 단위세대 `../MODEL-INSTRUCTIONS.md`, 단지배치 `../LLM-지침.md`, 동평면 JSON 형식 `../../dist/README.md`.
- 화면의 수치는 입력한 가정에 대한 기하 검토이며 법정 적합 판정이 아닙니다. 법령·조례 프리셋은 원문 확인일(2026-10-15) 이후 개정될 수 있습니다.
