[IO.File]::WriteAllBytes((Join-Path $PWD 'course-repo.bundle'),

막히면 내 작업은 남기고 새 폴더로 비교

현재 실습 폴더에서 git add -A와 git commit -m "수업 중간 저장"으로 저장한 뒤, apartment-course로 돌아와 아래를 실행합니다. 이미 같은 브랜치/폴더가 있으면 새 이름을 씁니다.

git worktree add -b check-stage1 ../check-stage1 3a5e6dc
git worktree add -b check-stage2 ../check-stage2 54b3670
git worktree add -b check-stage3 ../check-stage3 2f446b7

각 check 폴더에서 node server.cjs 8871 / 8872 / 8873으로 실행해 기존 실습과 비교합니다. JSON을 저장해 두고 자동저장 프로젝트가 섞이면 별도 포트나 시크릿 창을 씁니다.

처음 commit할 때 이름·이메일 설정을 요구하면 apartment-course 저장소에서 git config user.name "내 이름", git config user.email "내 이메일"을 설정합니다. 내보낸 JSON은 별도로 보관합니다.

Git 없이 최종 소스만 복원

위 Stage별 JSON은 최종 커밋의 모든 추적 파일을 Base64로 담았습니다. 테스트·빌드 도구·이미지도 포함합니다. 소스 JSON에는 Git 이력이 없으므로 커밋 이동에는 Git 자료를 사용합니다. 새 폴더에서 아래 명령을 복사해 실행하며 Stage 번호를 바꾸어 각각 복원합니다.

# Git이 없으면 Stage별 source.json을 새 폴더에 복원할 수 있습니다.
# 아래를 stage1/2/3 파일명으로 바꾸어 각각 실행합니다.
$courseSource = Get-Content './stage1-source.json' -Raw | ConvertFrom-Json
$courseTarget = [IO.Path]::GetFullPath((Join-Path $PWD 'stage1-source'))
if (Test-Path -LiteralPath $courseTarget) { throw '새 폴더 이름을 사용하세요.' }
foreach ($courseFile in $courseSource.files) {
  $coursePath = [IO.Path]::GetFullPath((Join-Path $courseTarget $courseFile.path))
  if (-not $coursePath.StartsWith($courseTarget + [IO.Path]::DirectorySeparatorChar)) { throw '폴더 밖 경로' }
  [IO.Directory]::CreateDirectory([IO.Path]::GetDirectoryName($coursePath)) | Out-Null
  [IO.File]::WriteAllBytes($coursePath, [Convert]::FromBase64String($courseFile.content))
}

검증 명령: 각 소스 폴더에서 node --test. JSON의 commit과 gitBlob으로 버전을 확인할 수 있습니다.
