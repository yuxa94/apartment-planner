CAD 환경이 없어도 진행하기

코어 읽기 실습은 core-dwg-source.json을 아래 명령으로 복원합니다. AutoCAD와 MCP가 준비되지 않았으면 cores.json의 치수·부품 목록을 Claude Code에 첨부해 동일한 동평면 조립 실습으로 진행합니다. 원본 DWG는 수정하지 않습니다.

$asset = Get-Content './core-dwg-source.json' -Raw | ConvertFrom-Json
foreach ($file in $asset.files) {
  $target = Join-Path $PWD $file.path
  [IO.Directory]::CreateDirectory([IO.Path]::GetDirectoryName($target)) | Out-Null
  [IO.File]::WriteAllBytes($target, [Convert]::FromBase64String($file.content))
}
